## Introduction

Welcome to my Build my own Shell challenge!

A shell is the program that interprets what you type into the terminal. It reads your commands, runs programs, and prints their output. Popular examples are Bash and ZSH.

## Scope of Build

I’ll start by implementing the core building blocks of every shell:

- Reading and parsing user input
- Built-in commands like `pwd` and `cd`
- Launching external programs

As I progress, I’ll implement more advanced features like:

- Piping and redirection
- Command history
- Autocompletion
… and more
